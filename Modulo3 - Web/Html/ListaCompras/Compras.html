Lista de Compras da Mãe

  1. Mouse

    É um dispositivo de mão que controla o movimento de um ponteiro na tela (normalmente a imagem de uma seta).
    Existem diversos tipos de mouse, mas o modelo mais comum tem o formato de um ratinho, por isso o nome em
    inglês: "mouse". Foi criado para facilitar a interação com o computador.

  2. Headset

    Um headset é um tipo de fone de ouvido que inclui um microfone, o que o torna ideal para jogos ou chamadas
    de vídeo. Over-ear, por outro lado, é uma descrição de design do fone em si.

  3. Keyboard

    É um tipo de periférico de entrada utilizado pelo usuário para a entrada manual no sistema de dados e comandos.
    Possui teclas representando letras, números, símbolos e outras funções, baseado no modelo de teclado das antigas
    máquinas de escrever. Um teclado de computador.

  4. Webcam

    Uma webcam é uma câmera digital que capta e transmite vídeo e áudio em tempo real, usualmente pela internet, sendo usada
    para videoconferências, transmissões ao vivo e gravações de vídeo. Elas podem ser integradas a computadores como laptops,
    ou ser dispositivos externos conectados via USB, e funcionam transformando a luz em sinais elétricos que são convertidos em
    dados digitais para serem transmitidos.
